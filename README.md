# First Commit — AWS × WeMakeDevs

Repository for my project at **First Commit**, the opening hackathon of the Bharat Builds Tour, held online from **September 17–20, 2026**.

## Status

Pre-event setup. The project idea and implementation will be added after the hackathon begins. This initial README documents the event and submission plan only.

## Project goal

Build a working solution to a real-world problem using AWS services or eligible AWS open-source tools. The problem statement, features, and technology choices are still to be decided.

## Planned submission

- A working prototype and this public source repository.
- A demo video of up to three minutes showing the solution and its AWS integration.
- A short writeup explaining the problem, implementation, AWS usage, and lessons learned.
- A live application URL if entering the Ship It track.

## Development

Project implementation starts when the hackathon officially opens. Setup instructions, architecture, and demo links will be added as the project takes shape. Any AI coding tools used will be disclosed in the submission writeup.
